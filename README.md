# Тест: органічні речовини

Онлайн-тест на 20 питань до презентації «Значення органічних речовин у житті людини».
Автор — Кратко Тимофій, І курс, група МОО, МТЕФК.

## Що це

Статичний сайт: HTML + CSS + звичайний JavaScript. Ніякого бекенду, збірки й залежностей.

- 20 питань, один варіант з чотирьох
- після кожної відповіді — правильний варіант і пояснення
- у кінці: відсоток, оцінка за 12-бальною шкалою, розбір усіх помилок
- **без реєстрації**: вписуєш ім'я — і проходиш
- особистий кабінет: історія спроб, найкращий бал, середній відсоток
- світла й темна тема, повністю адаптовано під телефон

Результати зберігаються в `localStorage` браузера — тобто на пристрої учня.
Нікуди не передаються й нікому не видні.

## Навантаження

Сайт статичний: сервер лише віддає три файли, вся логіка виконується в браузері.
Тридцять телефонів одночасно — це для CDN ніщо, лягти там нічому.

## Локальний запуск

```
python -m http.server 8256
```

Далі відкрити http://localhost:8256

## Публікація — Cloudflare Pages

1. Cloudflare → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. Вибрати приватний репозиторій `akm1t/organika-test`
3. Framework preset — **None**, build command лишити порожнім,
   output directory — `/` (корінь)
4. **Save and Deploy**

Репозиторій лишається приватним, а сайт стає публічним.

## Структура

```
index.html              — розмітка всіх екранів
assets/css/style.css    — стилі, палітра (біле · чорне · сіре · синє)
assets/js/questions.js  — питання, варіанти, пояснення
assets/js/app.js        — логіка: ім'я, тест, оцінка, кабінет
```

Щоб змінити питання — правити тільки `assets/js/questions.js`.
Поле `ok` — номер правильного варіанта, рахуючи з нуля.
